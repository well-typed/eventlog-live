# Dockerfiles for `eventlog-live`

This directory contains example containers for use with `eventlog-live`.

The `docker-compose.yml` file contains the applications needed to store and visualise eventlog data from an external program.
This requires running the external program side-by-side with `eventlog-live` as is done in, e.g., `examples/oddball/oddball-otlp-with-hT.sh`.
